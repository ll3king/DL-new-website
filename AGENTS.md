# Dandy Lane Cafe Website Project Delta

This file adds project-specific rules for this repository.

## Project Identity

Dandy Lane is a Hobart CBD hidden-lane breakfast-to-brunch cafe.

This repo is governed by two flywheels:

1. `AEO / GEO / AI Search Optimization`
2. `Visual Taste / Frontend / Performance`

Flywheel 1 is a standalone feature area.
Its initial optimization has already been completed and validated.
Default Flywheel 1 work is maintenance mode: keep factual consistency and answerability.

## Current Priority

`Visual Taste / Frontend / Performance` is the current urgent priority.

For any frontend, homepage, menu, FAQ, story presentation, visual system, mobile UX, or performance task:

1. read [README.md](./README.md)
2. read [docs/project-current-overview-and-doc-governance.zh-CN.md](./docs/project-current-overview-and-doc-governance.zh-CN.md)
3. read [docs/flywheel-2-visual-taste-frontend-performance.md](./docs/flywheel-2-visual-taste-frontend-performance.md)
4. read [docs/project-module-code-boundary-map.zh-CN.md](./docs/project-module-code-boundary-map.zh-CN.md)
5. only then plan or implement

Do not jump straight into UI implementation without checking Flywheel 2 rules first.

## Workflow

Active workflow:

`Stitch -> Codex via MCP -> repo implementation -> Taste / Impeccable visual QA -> performance QA`

Stitch is the default design exploration canvas.
Figma is not the default workflow.
Gemini is not part of the current workflow.

## Flywheel 2 Intent

Frontend work should make the website feel:

- warmer
- more appetising
- more human
- more specific to Dandy Lane
- more visually tasteful

while protecting:

- speed
- mobile usability
- performance

Core memory anchors to strengthen:

- Wine-Infused Benedict
- Scotch Steak Sandwich
- Specialty Coffee
- hidden lane / Collins Court / Hobart CBD

## Deprecated Defaults

Do not treat these as default project logic:

- SEO-first narrative
- n8n workflows
- Google Sheets / Telegram automation as default website logic
- Gemini workflow
- Figma workflow
- wedding / event / styling examples
- release checks as the main project narrative

Language rule:

- use `AEO / GEO / AI Search Optimization` as the strategic language
- `SEO` may only appear for technical infrastructure such as schema, crawlability, canonical URLs, metadata, internal links, robots, sitemap, or structured data

## Boundaries

- Do not expand Flywheel 1 during Flywheel 2 documentation or frontend work unless the task explicitly requires it.
- Do not introduce new default tools or workflows that compete with the current Stitch-to-Codex path.
- Do not let booking, AI chat, or SMS history redefine the website-wide project narrative.
