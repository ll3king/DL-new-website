## Agent Swarm Model

### Controller

Owns scope, source priority, final decision, and risk.

Responsibilities:

- choose target intent clusters
- assign specialist agents
- approve or reject public actions before posting
- decide what counts
- keep the project language as AEO / GEO / AI Search Optimization
- stop work that becomes spammy, generic, or unsupported

Non-goals:

- no fake reviews
- no hidden-affiliation posting
- no broad SEO-first content expansion

### Reference Scout

Finds and verifies external source evidence.

Responsibilities:

- capture Google Business Profile / Maps facts
- capture Tripadvisor listing and review-language evidence
- capture local tourism and directory listings
- capture Apple Maps / Bing Places if available
- classify each source as count, revise, monitor, or reject

Required evidence:

- URL
- checked date
- source type
- facts confirmed
- facts contradicted
- target anchors present
- quality score
- reviewer recommendation

### Community Scout

Finds Reddit/forum opportunities.

Responsibilities:

- search target local-intent threads
- reject old, spammy, or low-fit threads
- identify threads where Dandy Lane would genuinely help
- record whether Dandy Lane is already mentioned by independent users
- prepare a participation risk rating

Required evidence:

- thread URL
- thread title/question
- currentness
- relevance
- whether Dandy Lane is already mentioned
- whether affiliation must be disclosed
- whether a link is necessary
- participate / monitor / reject decision

### External Signal Operator

Executes approved external actions only after Controller pre-check.

Responsibilities:

- prepare Google Business Profile update checklist
- prepare listing correction requests
- prepare owner/staff review replies where relevant
- prepare Reddit/forum replies only when context justifies it
- capture live evidence after submission

Operating rule:

`Drafting is not publishing. Public Reddit/forum action needs Controller approval and Strict Reviewer pre-post approval first.`

Listing corrections and evidence capture can proceed with Controller approval.
Public community participation has the stricter reviewer gate because it creates reputation and platform-compliance risk.

### Tracker

Measures whether external proof changes actual discovery signals.

Responsibilities:

- run AI answer checks
- record Google visibility metrics if available
- record map / direction / booking / phone signals if available
- track whether Dandy Lane appears for target prompts
- track which external sources are cited or repeated

Minimum fields:

- platform
- date
- prompt/query
- result
- cited sources
- Dandy Lane shown: yes/no
- factual accuracy
- follow-up action

### Strict Reviewer

Rejects weak, risky, or unverified signals.

The reviewer does not draft posts and does not operate accounts.

Responsibilities:

- verify evidence can be rechecked
- reject hidden affiliation
- reject copied or generic replies
- reject unverifiable sources
- reject factual conflicts unless isolated with a risk note
- decide pass, conditional pass, revise, or reject

## Reviewer Scoring

Total: 100 points.

| Area | Points | Pass Requirement |
|---|---:|---|
| Entity and location consistency | 20 | Google Business Profile captured and no major contradiction remains. Equivalent map source requires an explicit Strict Reviewer exception. |
| Product anchor reinforcement | 20 | At least two independent sources support brunch/coffee and at least one signature product anchor. |
| Community proof integrity | 20 | Reddit/forum activity is relevant, transparent, non-spammy, and recheckable. |
| AI retrieval evidence | 20 | At least two AI systems checked with dated prompts and factual result notes. |
| Evidence quality and governance | 20 | Every counted signal has URL, date, excerpt/screenshot, source independence, risk note, and reviewer decision. |

Decision bands:

- 90-100: pass
- 80-89: pass with minor notes
- 70-79: conditional pass
- 60-69: revise
- below 60: reject

Hard rejection triggers:

- fake customer voice
- hidden affiliation
- spam-link pattern
- unverifiable screenshot/excerpt
- stale thread treated as current proof
- factual conflict ignored
- website-only evidence counted as external proof
- SEO-first language used as strategic direction
